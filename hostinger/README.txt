NeuroEnfants — site prêt pour Hostinger
=======================================

Contenu de ce dossier (tout est déjà inclus, aucun autre fichier n'est nécessaire) :

  index.html    la page complète (français)
  styles.css    tous les styles
  app.js        galerie photos, notifications d'achat, choix du plan et redirection
  favicon.ico   icône du site
  assets/       toutes les images de la page

Comment mettre en ligne sur Hostinger
-------------------------------------
1. Connectez-vous à hPanel > Fichiers > Gestionnaire de fichiers.
2. Ouvrez le dossier public_html (videz-le s'il contient un site de démonstration).
3. Envoyez le CONTENU de ce dossier (index.html, styles.css, app.js, favicon.ico et le dossier assets)
   directement dans public_html — et non le dossier "hostinger" lui-même.
4. Ouvrez votre domaine : la page s'affiche immédiatement.
